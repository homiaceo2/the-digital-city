# The Digital City — Genesis City

Standalone interactive prototype of a digital advertising city.

## Run
Open `index.html` in a browser. No build step or dependencies.

## Included
- 50 simulated advertising lots across five districts
- Zoom, drag, filters and search
- Lot details and indicative pricing
- Founder Spaces and occupied lots
- Local-only request demonstration

## Not implemented
Authentication, database, uploads, real inventory, payment processing, auctions and live deployment. All availability is illustrative.

## Next steps
Migrate to React/Next.js and a rendering engine, add Supabase authentication and row-level security, server-validated inventory holds, Stripe checkout/webhooks, moderation and analytics.
